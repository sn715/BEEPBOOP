# components/

Reusable UI used on more than one screen. One component per file, named in PascalCase (`EntryCard.tsx`).

Expected first components, based on the mockups:

- `EntryCard`: a row in the diary (artist, venue, date, photo thumbnail)
- `MonthHeader`: the "SEPTEMBER 2026" divider in the diary
- `StarRating`: show and set a 1–5 star rating
- `PhotoCarousel`: swipeable photos and clips on a journal entry
- `PrivacyPicker`: public / friends / private, with the logo-dot icons
- `Logo`: the two dots and the "bridge" wordmark
